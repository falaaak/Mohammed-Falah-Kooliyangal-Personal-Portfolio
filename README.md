# Mohammed Falah Kooliyangal - Premium Portfolio

A museum-quality, cinematic personal portfolio designed for Mohammed Falah Kooliyangal, a Clinical Application Specialist and aspiring Data Analyst.

## Architecture & Tech Stack

This project is built using an ultra-modern, dependency-free vanilla stack to ensure maximum performance, bespoke interactions, and long-term maintainability.

- **HTML5:** Semantic, accessible structure optimized for SEO.
- **CSS3:** Advanced CSS featuring variables, fluid typography (`clamp()`), complex mesh gradients, SVG noise texturing, and hardware-accelerated animations. No Tailwind or Bootstrap.
- **JavaScript (ES6+):** Pure Vanilla JS powering intersection observers, layered parallax scrolling, cursor-reactive lighting, magnetic components, and dynamic statistic counters. No React or jQuery.

## Features

- **Cinematic Environment:** A deep blue `#04070D` base with slow-moving aurora gradients and subtle floating particles.
- **Museum-Quality Typography:** Bold, expressive `Space Grotesk` paired with highly readable `Manrope`.
- **Advanced Interactions:** 
  - Smooth layered parallax on scroll.
  - Magnetic buttons and navigation links.
  - Cursor-reactive radial lighting.
  - Staggered, cinematic scroll reveals.
- **Responsive Design:** Flawless execution across Mobile, Tablet, and Desktop breakpoints.

## Usage & Deployment

To run this project locally, simply serve the directory using any static file server:

```bash
npx serve .
# or
python3 -m http.server 8000
```

Deploying to Vercel, Netlify, or GitHub Pages requires zero build steps—simply push the repository.
